# Портфолио w01kn3w

Небольшой адаптивный сайт на HTML и CSS. Без сборки и JavaScript.

Сайт: https://w01kn3w.github.io/portfolio/

Откройте `index.html` в браузере для локального просмотра. Тексты и ссылки находятся в `index.html`, оформление в `style.css`.

Шрифты Manrope и Lora распространяются по SIL Open Font License, лицензии находятся в `assets`.

Публикация через GitHub Pages из корня ветки `main`. После изменения файлов отправьте коммит в эту ветку.
